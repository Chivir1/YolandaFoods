# Yolanda Foods — E-Commerce Web Platform

Official storefront and order management platform for **Yolanda Foods** (Lagos, Nigeria), providing farm-fresh produce and food staples directly to homes and restaurants.

## Project Structure
- `index.html`: Main single-page application integrating the Alight Motion opening splash, catalog, live search, cart drawer, Lagos delivery calculator, and WhatsApp direct checkout.
- `step1_brand_spec.md`: Official brand identity, color palette, and vector logo specifications.
- `step4_catalog_spec.md`: Product catalog pricing, variants, nutritional details, and packaging specs.
- `/assets/branding/`: Master vector logo (`.svg`) and preview image (`.png`).
- `/steps_archive/`: Individual, vetted step modules (Steps 1 through 13) including the secure review moderation portal and NDPR privacy policies.

## Key Features
- **Doorstep Delivery Scope**: Lagos State, Nigeria.
- **WhatsApp Direct Order Hotline**: `07040275628` (international: `+2347040275628`).
- **Dynamic Lagos Zone Delivery Fee Calculator**: Lekki, Ikeja, Surulere, Ajah, Yaba, Magodo, Festac, etc.
- **Interactive Review Moderation Desk**: Protected review vetting portal for store owners.
- **Privacy & Cookie Banner**: Compliant with Nigeria Data Protection Regulation (NDPR).
